Para este proyecto contaré con dos bases de datos:
1. https://www.cultura.gob.cl/participacioncultural/wp-content/uploads/sites/15/2025/08/cuadros_estadisticos_indicadores_especificos-enpccl_2024.xlsx

**Autor:** Los datos corresponden a la Encuesta Nacional de Participación Cultural y Comportamiento Lector 2024 (ENPCCL), elaborada por el Ministerio de las Culturas, las Artes y el Patrimonio, junto con el Instituto Nacional de Estadísticas (INE). La encuesta fue publicada durante 2025 y sus resultados y bases de datos están disponibles públicamente en el sitio del Ministerio de las Culturas. La base será obtenida desde la plataforma oficial del Ministerio, específicamente desde la sección de resultados de la ENPCCL 2024.
 https://www.cultura.gob.cl/participacioncultural/resultados-enpccl-2024/

**Contenido:** La base contiene información sobre los hábitos de participación cultural y comportamiento lector de la población residente en Chile. Para esta investigación interesan especialmente las variables relacionadas con: cantidad de libros leídos,  frecuencia de lectura, formato de lectura, edad, región y características sociodemográficas.

**Pertinencia:** Esta base es fundamental porque permite conocer cuánto y cómo leen los chilenos. La información sobre cantidad y frecuencia de lectura permitirá establecer diferentes perfiles de lectores y posteriormente calcular cuánto podría gastar cada uno si comprara sus libros nuevos. Las variables de formato, edad y región también permitirán explorar diferencias entre distintos grupos de población


**Metodología:** Los datos fueron levantados mediante la Encuesta Nacional de Participación Cultural y Comportamiento Lector 2024, realizada por el Ministerio de las Culturas, las Artes y el Patrimonio junto con el INE. Al tratarse de una encuesta oficial, los datos fueron recopilados mediante instrumentos de investigación estandarizados y posteriormente procesados para generar una base de datos estadística. Para este proyecto no será necesario realizar nuevamente el levantamiento de estas variables, sino utilizar la base pública disponible y seleccionar aquellas variables directamente relacionadas con la investigación.

2. Para la segunda base de datos, se creara una que no exite y es de acuerdo a precios y características de libros en Chile.
**Autor:** Esta será una base de datos construida por el equipo de investigación, ya que no cuentan con una base pública única que reúna de manera comparable los precios y características de libros comercializados en distintas librerías chilenas. Los datos serán obtenidos directamente desde los catálogos online oficiales de librerías chilenas, entre ellas:
* Feria Chilena del Libro.
* Antártica.
* Contrapunto.
* Buscalibre.
* Green Libros.
* ChileBooks.

También podrán incorporarse otras librerías si cumplen con los criterios definidos para la muestra. Para cada registro se guardará la página web de origen y la fecha en que se realizó la consulta, permitiendo verificar posteriormente los precios.


**Contenido:** La base estará compuesta por información cuantitativa y categórica correspondiente a una muestra de libros disponibles para la compra en librerías chilenas.


**Pertinencia:** Esta base permitirá responder la pregunta central de la investigación: ¿cuánto cuesta tener un hábito lector en Chile?
Mientras la ENPCCL permite conocer cuánto leen las personas, esta base permite conocer cuánto cuestan los libros. Al cruzar ambas fuentes será posible estimar el gasto anual asociado a diferentes frecuencias de lectura.
Además, permitirá analizar diferencias de precios según género, editorial, formato y cantidad de páginas, junto con indicadores como el precio promedio y el precio por cada 100 páginas.


**Metodología:** La información será recolectada mediante inscripción manual de datos desde los catálogos online de librerías chilenas. Se seleccionará una muestra de aproximadamente 100–200 libros, procurando incluir distintos géneros, editoriales, autores, extensiones y rangos de precios. Cuando sea posible, también se registrarán títulos disponibles en más de una librería para poder comparar sus precios. Cada integrante podrá encargarse de una parte de la muestra o de determinadas categorías, pero utilizando los mismos criterios y variables para mantener la consistencia de la información. Una vez terminada la recolección, los datos serán revisados para detectar:
* Registros duplicados.
* Errores de digitación.
* Información faltante.

Posteriormente se calcularán los indicadores necesarios para el análisis y visualización de la investigación.
